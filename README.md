# RMR add-ons

Home Assistant add-on repository.

Add it in **Settings → Add-ons → Add-on store → ⋮ → Repositories**: `https://github.com/reedr/ha-addons`

| Add-on | What it does |
|---|---|
| [LLM Loaded-Model Proxy](llm_loaded_proxy/) | OpenAI-compatible proxy that sends every request to whatever model a llama.cpp router has loaded |
